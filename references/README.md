## 使用方式

1. 先读各题 README 中的「与赛题子问题的对应」表，再按需精读。
2. 论文参考文献请按 GB/T 7714-2015 著录；LaTeX 直接 `\bibliography{references/problem-A/refs}`。
3. 正式引用前建议再打开 DOI 核对年卷期页码（跨库元数据偶有出版年差一年）。
