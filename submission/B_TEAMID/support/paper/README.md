# 论文编译与提交

版式按 `competition_question/（必读）第十一届湖南省研究生数学建模竞赛论文格式规范.docx`。承诺书用同目录官方 Word **原件打印签字，不得改版式**。

## 编译

```bash
cd paper
bash compile.sh
```

得到 `main.pdf`（约 16 页）。页眉空白，页脚中部阿拉伯页码自 1；PDF 元数据无作者、无队号。

## 提交前必须改名

命名为 **选题+队号.pdf**，例如 `B202618001001.pdf`。队号见 `competition_question/第十一届湖南省研究生数学建模竞赛参赛队伍编号.xlsx`，仓库内用占位符 `B_TEAMID`。

1. 把 `main.pdf` 复制为 `B<队号>.pdf`。
2. 承诺书按官方 Word 原件打印签字。
3. zip 内 PDF 文件名与论文文件名一致；体积不超过 20 MB。
4. 论文与支撑材料均不得出现姓名、学校、队号。

## 与格式规范对照

| 规范原文 | 本稿 |
|----------|------|
| 第 1 页：题目、摘要、关键词 | 竞赛名（对齐规范 Word 题头）+ 三号黑体题目 + 摘要 + 关键词 |
| 第 2 页起正文（可含目录） | 正文从「1 问题重述」起，无目录 |
| 页脚中部阿拉伯页码从 1 | `fancyhdr` 页脚居中 |
| 页眉不得有参赛队号 | 页眉空白 |
| 题目三号黑体加粗居中 | `\heiti\zihao{3}\bfseries` |
| 一级小三黑体加粗左齐 | `\heiti\zihao{-3}` |
| 二级四号黑体加粗左齐 | `\heiti\zihao{4}` |
| 三级小四黑体加粗左齐 | `\heiti\zihao{-4}` |
| 正文小四宋体 / 英文 Times New Roman | Fandol 宋体；英文 TeX Gyre Termes（Times 同类） |

| 图注、表头楷体 11 号 | `\kaishu` 11pt |
| 正文 ≤ 25 页 | 第 1 页摘要，第 2–14 页正文，第 15 页文献，第 16 页附录 |
| 附录含主要源程序 | 附录 A 节选；完整代码在 zip |
