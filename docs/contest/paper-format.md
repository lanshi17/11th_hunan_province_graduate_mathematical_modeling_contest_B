# 论文格式规范

来源：`competition_question/（必读）第十一届湖南省研究生数学建模竞赛论文格式规范.docx`

## 结构

1. **第 1 页**：题目、摘要、关键词。
2. **第 2 页起**：正文（可含目录）。
3. 页码位于页脚中部，阿拉伯数字从 `1` 起连续编号。
4. **匿名**：正文与页眉不得出现任何可识别答题人身份的信息（含参赛队号）。

## 篇幅与命名

- 正文控制在 **25 页以内**。
- 计算相关内容须在附录给出主要源程序。
- 论文格式：PDF。
- 命名：`选题 + 队号`，例如 `A202618001001.pdf`。
- 队号由组委会统一编号，随赛题发布（见 `competition_question/第十一届湖南省研究生数学建模竞赛参赛队伍编号.xlsx`）。
- 未按格式或命名要求提交的论文可能被取消评奖资格。

## 提交压缩包

- 格式：zip。
- 内容：以 `选题+参赛队号` 命名的 PDF 论文 + 支撑材料。
- 支撑材料一般包括：题目给定以外的数据、全部可运行源程序（含 Excel、SPSS 等交互命令）。
- 支撑材料中也不得出现身份信息。
- 体积一般不超过 **20 MB**。
- 由各高校负责老师统一收齐后，在截止时间前提交组委会邮箱。

## 排版

| 元素 | 要求 |
|------|------|
| 论文题目 | 三号黑体加粗，居中 |
| 一级标题 | 小三号黑体加粗，左对齐 |
| 二级标题 | 四号黑体加粗，左对齐 |
| 三级标题 | 小四号黑体加粗，左对齐 |
| 正文中文 | 小四号宋体 |
| 正文英文 | Times New Roman |
| 段落 | 首行缩进 2 字符，单倍行距，段前段后 0.25 行 |
| 图注、表头 | 楷体 11 号 |

参考文献按 GB/T 7714-2015 规范著录。解释权属于竞赛组委会。
