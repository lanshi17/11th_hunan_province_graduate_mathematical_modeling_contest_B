## 组织

| 项目 | 内容 |
|------|------|
| 主办 | 湖南省教育厅 |
| 承办 | 湖南人文科技学院 |

## 参赛对象与组队

- 对象：省内研究生培养单位的在籍研究生。
- 形式：团队参赛，专业不限；鼓励跨院系、跨专业，**不得跨单位**。
- 规模：每队不超过 3 人；同一单位参赛队伍数限定为 2–30 支。
- 报名：不接受个人直接报名。各单位须先组织校内选拔，再报省赛。
- 报名截止：2026-08-19 18:00。
- 报名材料：《报名表》扫描 PDF 及原始 Word，由培养单位发送至组委会邮箱。

## 奖项

| 奖项 | 比例 / 规则 |
|------|-------------|
| 一等奖 | 有效参赛队伍的 10% |
| 二等奖 | 15% |
| 三等奖 | 25% |
| 优秀指导教师奖 | 授予一等奖团队指导教师 |
| 优秀组织奖 | 原则上不超过 4 个单位 |

评审排序后，**前 15% 为一等奖候选队**，进入现场答辩；其余按得分比例评二、三等奖。

## 竞赛时间与提交

| 节点 | 时间 |
|------|------|
| 赛题发布 | 2026-08-20 08:00（官网与领队微信群同步） |
| 竞赛窗口 | 2026-08-20 08:00 至 2026-08-24 12:00 |
| 提交截止 | 2026-08-24 12:00 交至所在培养单位，由领队统一发送 |

提交清单：

1. 参赛承诺书 PDF
2. 参赛论文 PDF

查重：自建库 + 知网。认定违规则取消资格并通报。**论文附录须含主要程序代码**，否则按违规论文处理。

评审专家：省内数学学科从事教学或科研的教授，或具有博士学位的副教授。
