# 参赛承诺书要点

来源：`competition_question/（必读）第十一届湖南省研究生数学建模竞赛承诺书.docx`

打印后按原格式填写、签名；**不得改动页面内容与格式**。填写错误可能导致取消评奖资格。

## 承诺事项

1. 已阅读竞赛规则。
2. 竞赛开始后，队员不得以任何方式（电话、邮件、网上咨询等）与队外任何人（含指导教师）讨论赛题。
3. 不得抄袭；引用他人成果或公开资料须在正文引用处和参考文献中明确列出。
4. **须合法合规使用文献、软件和 AI 工具，不得侵犯知识产权**；否则失去评奖资格并可能被严肃处理。
5. 授权组委会以任何形式公开展示论文（网上公示、书籍期刊及其他媒体发表等）。

## 须填写字段

- 参赛题号（A 或 B，择一）
- 完整参赛编号
- 所属学校全名
- 三名队员打印后签名
- 指导教师仅限 1 名，或写「指导教师组」，打印后签名
- 日期
- 承诺书 PDF 命名：`选题+队号_承诺书.pdf`
