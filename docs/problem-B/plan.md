## 2. 问题一:多源数据一致性校正与可信性评价

### 2.1 方法定位与文献依据

本问在化工过程控制中称**数据调和**(data reconciliation):在守恒律硬约束下,以加权最小二乘对冗余观测做最小扰动校正,并用统计检验辨识粗差(`Crowe1996data`;`Narasimhan1999data` 给出冗余度、可观测性与粗差检验的完整体系)。电力系统同源方法即 WLS 状态估计(`Schweppe1970power`),坏数据辨识采用标准化残差最大检验 LNR(`Abur2004power`);多源量测(月度监测 vs 年度汇总 vs 变电站辅助计量)融合的现代综述见 `Cheng2023survey`。**直接同构的实证范例**:de Chalendar & Benson 在美国电网上对多源监测数据做守恒约束调和并实时追踪排放(`deChalendar2021physics`),其数据基础即平衡区交换电量(`deChalendar2019tracking`)——与本题"区域月度监测 + 通道计量 + 能量平衡"设定一一对应,论文引言与模型假设均可对标。论文写作时按"数据调和 = 面向能量平衡的广义状态估计"来组织,术语与检验统计量全部有出处。

### 2.2 异常与不一致识别

1. **缺失值**:附件 1A 已知 4 处空值(2025-04 A7 风电、2025-05 A4 水电、2025-09 A2 工业用电与终端合计),调和模型中作为自由变量(大方差观测)处理。
2. **结构性校验**:
   - 分部门用电之和 vs 终端用电合计;
   - 月度累加 vs 附件 2A 年度汇总(逐区域逐字段相对偏差);
   - 附件 1B 隐含损耗率(1 − 受端/送端)vs 附件 2B 工程线损率;
   - E10 年度受端 > 送端(题面预留矛盾);通道是否超月度容量上限;
   - 区域能量平衡式 (1) 残差 r_{i,t} 的**标准化残差检验**,|r_N| > 3 判为可疑粗差(`Abur2004power` 的 LNR 准则)。
3. **口径不一致**:附件 2B 变电站入口电量合计与区域终端用电的覆盖率差异,识别计量口径差别。

### 2.3 数据校正模型(广义数据调和)

决策变量:全部月度观测的校正值 x̂(分源发电、省外输入、分部门用电、通道送/受端电量)与通道损耗率 η_e。

目标函数(最小加权扰动,`Crowe1996data` 标准形式):

min Σ_k ((x̂_k − x_k)/σ_k)² + λ Σ_e (η_e − η_e^eng)²

- σ_k 按计量类型取相对不确定度(发电/用电 1–2%,通道计量 2–3%;缺失值 σ→∞);月度监测与年度汇总两套系统赋不同信任权重,冲突由权重仲裁;
- 第二项将损耗率正则化到附件 2B 工程记录值附近。

硬约束:

1. 逐区域逐月能量平衡:Ĝ_{i,t} + Î_{i,t} + Σ_j T̂_{j,i,t}(1−η_e) = D̂_{i,t} + Σ_j T̂_{i,j,t} + L̂_{i,t};
2. 分部门用电之和 = 终端合计;
3. 月度之和 = 年度汇总(带松弛,松弛进目标);
4. 通道受端 = 送端 × (1−η_e);T̂ ≤ 月度容量上限;变量非负;
5. η_e ∈ [0.5, 2] × 工程值。

η_e·T̂ 双线性项用**两步迭代**处理:固定 η 解凸 QP → 由校正后送/受端电量更新 η → 交替 2–3 轮;论文报告迭代收敛曲线(数据调和中处理非线性守恒项的惯用做法,`Narasimhan1999data`)。

### 2.4 通道损耗估计与观测影响度

- η̂_e = 1 − Σ_t 受端校正 / Σ_t 送端校正,与工程值对比并给出近似置信区间;
- **影响度分析**:(a) QP 的 KKT 灵敏度矩阵给出每个观测对校正解的线性影响,输出 Top-N 排名(冗余度低的观测影响大,`Narasimhan1999data` 冗余理论);(b) 对可疑观测(E10、A2 九月、年度冲突项)做 ±5% 留一扰动重解,量化传播幅度。结论落到"优先加强哪些计量点",供 Q5 使用。

产出:校正前后对比表、平衡残差热力图、损耗率估计表、影响度排名。

## 3. 问题二:碳流追踪与责任分担

### 3.1 方法定位与文献依据

采用**电力系统碳排放流**(carbon emission flow)模型:以比例共享原则(proportional sharing,潮流追踪奠基文献 `Bialek1996tracing`、`Kirschen1997contributions`)把碳排放作为依附于电量的虚拟流,沿网络从发电侧推送到消费侧;核心量为**节点碳势**(nodal carbon intensity)ρ_{i,t},由康重庆团队系统建立(`Kang2012carbon` 概念,`Kang2015carbon` 完整网络模型),近年扩展综述见 `Chen2024towards`、`Hu2025study`。责任核算三口径:生产侧/消费侧定义(`Peters2008production`、`Davis2010consumption`),共担责任的公理化与一致性公式(`Lenzen2007shared`、`Gallego2005consistent`),中国区域间电力隐含碳转移的实证背景(`Feng2013outsourcing`、`Xie2017provincial`)。

### 3.2 节点碳势模型

对每月 t,由 Q1 校正后的 T̂ 取通道净流向构成有向图,节点碳势满足"入流碳量守恒、出流按同一碳势混合"(`Kang2015carbon` 式):

ρ_{i,t} · (G_{i,t} + I_{i,t} + Σ_j F_{j→i,t}(1−η)) = Σ_s G^s_{i,t}·EF_s + I_{i,t}·EF_i^out + Σ_j F_{j→i,t}(1−η)·ρ_{j,t}

- EF_s:火电 0.82 / 水电 0.024 / 风电 0.011 / 光伏 0.045;EF_i^out 按附件 3A 分区域;
- 8 节点线性方程组逐月求解(无环时可拓扑递推,有环时直接解线性系统);
- 线损碳排归属主口径"送端承担",备选口径"受端承担"做敏感性(碳流模型中损耗处理的标准讨论,`Kang2015carbon`)。

### 3.3 责任核算与共担设计

1. **终端碳强度**:8 区域 × 12 月 ρ_{i,t} 曲线 + 来源分解堆叠图(本地分源/省外/省内输入);
2. **生产侧责任** E_i^P(`Peters2008production` 定义):本地发电碳排放(省外输入归属口径单独说明);
3. **消费侧责任** E_i^C = Σ_t D_{i,t}·ρ_{i,t}(`Davis2010consumption`);
4. **共担方案**:E_i^λ = λ·E_i^P + (1−λ)·E_i^C(`Gallego2005consistent` 分担系数形式)。λ 的确定:主方案 λ = 0.5,备选按区域"受益程度"(外送电收益占比)加权;**博弈论加分项**:8 区域可精确枚举 2^8 联盟,直接计算 Shapley 值分摊作为第三种责任方案,与 λ 加权对比——中国电力行业减排责任的合作博弈分摊先例见 `Qin2020cooperative`,电网主体碳义务合作博弈及其核的存在性论证见 `Zhou2019cooperative`;按 `Lenzen2007shared` 的公理要求校验**责任守恒**——各口径下全省总责任均等于全省总排放,不重复不遗漏,作为模型正确性证据表;
5. 输出 Q3 所需的 2025 年区域基准碳强度 ρ_{i,2025}(用电量加权年均)。

## 4. 问题三:区域碳预算分配与低碳项目组合 MILP

### 4.1 方法定位与文献依据

两层结构。**碳预算分配层**:把附件 4B 的全省年度消费侧碳上限分解到区域,分配准则采用公平(人均/现状)与效率(强度)混合方案——准则体系依据碳配额分配综述 `Zhou2016carbon`,混合权重形式借鉴 `Raupach2014sharing` 的"惯性(现状份额)+ 公平(规模份额)"凸组合:B_{i,y} = [w·s_i^inertia + (1−w)·s_i^equity]·CAP_y,主方案 w = 0.5,w ∈ {0.3, 0.7} 做敏感性;中国省级(电力部门)配额分配的同类实证:`Wang2013regional`(公平-效率组合准则)、`Cui2021allocation`(熵权 + 零和 DEA)、`Bai2024allocation`(省级电网最新方案),论文据此论证准则选择并可借 ZSG-DEA 思想说明"区域预算之和恒等于全省上限"的零和性质。区域预算作为软约束(违约罚)进入 MILP,全省硬上限保留,避免分配方案不可行。**项目组合层**:多年期投资-运行耦合 MILP,建模范式遵循电源扩展规划综述 `Koltsaklis2018generation`(投资变量 + 运行变量 + 逐年耦合约束),近年低碳协调调度实例 `Zhang2024two`。

### 4.2 决策变量

- x_{p,t} ≥ 0:项目 p 在年 t 开工规模;y_{p,t} ∈ {0,1}:开工指示;
- s_r ∈ {0,1}:协同触发(SYN-A2/A4/A6/A8);
- 运行层:各区域各年省外输入 I_{i,y}、区域间净输电 F_{e,y}、缺供松弛 u_{i,y}。

### 4.3 效益结转与约束

已投运规模 X_{p,y} = Σ_{t ≤ y−c_p} x_{p,t}(开工年 t、周期 c_p,自 t+c_p 年起满效益;投资计入开工年),节电/新增清洁供电/新增用电/直接减排/输电容量/线损率降低均正比于 X_{p,y}。

1. **规模**:Σ_t x_{p,t} ≤ 最大总规模;x_{p,t} ≤ 年度最大开工规模·y_{p,t};
2. **资源**:C1–C5 省级年度施工资源上限(附件 5C);
3. **投资**:年度投资上限(附件 5C);
4. **互斥**:y_{P33,t} + y_{P35,t} ≤ 1;y_{P34,t} + y_{P35,t} ≤ 1;
5. **协同**:s_r 触发条件(四项目累计规模均 ≥ 30% 上限)与 P05/P13/P21/P29 节电 ×1.05 的效益增量,用大 M 线性化;
6. **供需平衡**(逐区域逐年):基础供给(附件 3B 电源规模,以 2025 校正数据标定利用小时)+ 新增清洁供电 + 省外输入 + 净受电 ≥ (需求基数×(1+g_i)^n + 电气化新增 − 节电)×0.97;关键负荷底线单列;
7. **通道容量**:|F_{e,y}| ≤ 12×(月度基准容量 + 升级增量);省外输入 ≤ 年容量上限;
8. **碳约束**:全省硬上限(附件 4B)+ 区域软预算(§4.1);基准碳强度 = ρ_{i,2025} × 调整系数_y,叠加项目直接减排;交通电气化新增用电按当年区域碳强度计间接排放,不重复计算。

### 4.4 目标函数与求解分析

min Σ 投资(8% 折现,做无折现敏感性) + β·高碳购电成本代理 + M·Σ u_{i,y} + γ·区域预算违约罚

- 规模约 350 连续 + 350 个 0-1 变量,HiGHS 秒级;
- **优先项目**:约束影子价格 + 单位减排成本排序交叉验证 MILP 选择;
- **方案稳健性**:投资上限 ±10%/±20%、碳上限 ±5% 网格重解,项目组合 Jaccard 相似度 + 总成本变化率,回答题面"方案是否显著变化"。

## 5. 问题四:送端碳排不确定性下的鲁棒滚动调控

### 5.1 方法定位与文献依据

附件 6A 的归一化偏离 z 与年度预算 Γ_t 正是**预算不确定集**(`Bertsimas2004price`;鲁棒凸优化一般理论 `BenTal1998robust`),题面等于指定了 Bertsimas–Sim 路线。三层递进:

1. **静态压力测试**:固定 Q3 方案 x*,在 S0–S3 情景下重算逐年碳排放与越限量(概率碳流对照 `Sun2024modeling`);
2. **静态鲁棒对等式**:碳约束不确定项 Σ_i I_{i,y}·ē_{i,y}·(1+(ξ^U_{i,y}−1)z_{i,y}),内层 max 为 LP,对偶化引入 π_y、μ_{i,y} 得线性鲁棒对等约束(`Bertsimas2004price` 定理),嵌回 MILP 重解得鲁棒方案 x^R;
3. **两阶段可调鲁棒 + 滚动调控**:2026–2027 已开工项目为"此时此地"变量,2028–2030 追加项目与购电/潮流调整为"观望"变量(可调鲁棒框架 `BenTal2004adjustable`;电力两阶段鲁棒标杆 `Bertsimas2013adaptive`)。求解主方案用**列约束生成 C&CG**(`Zeng2013solving`,两阶段鲁棒标准精确算法;本题不确定维度仅 8 区域 × 3 年,预算集顶点少,预计 2–4 轮收敛),备选为小规模最坏情景枚举;区域间输电作为第二阶段补偿手段的结构对标联络线自适应鲁棒调度 `Li2016adaptive`;"逐年观测 ξ → 滚动重优化"机制依据滚动时域框架 `Silvente2015rolling`,近年两阶段鲁棒调度实例 `Ju2024data`、`Shen2024two`。

### 5.2 抗风险代价

对比确定性方案 x* 与鲁棒方案 x^R 的总投资、五年减排量、最坏情景越限量;画 Γ ∈ [0, 3] 的成本-鲁棒性权衡曲线——即 `Bertsimas2004price` 的 **price of robustness**,全文核心亮点图;两阶段方案给出 S3 最不利情景下调整前后碳排放轨迹对比。

## 9. 论文得分点设计

1. Q1 以数据调和/状态估计规范术语组织(冗余度、可观测性、LNR),每个统计量给出处;

3. Q3 影子价格解读 + Jaccard 稳定性分析,分配准则引 `Zhou2016carbon`/`Raupach2014sharing` 而非拍脑袋;
4. Q4 price-of-robustness 曲线直接对话 `Bertsimas2004price`,两阶段结构对话 `Bertsimas2013adaptive`,求解算法对话 `Zeng2013solving`(C&CG 收敛过程表是加分图);

6. 所有口径选择(损耗先验、σ、λ、w、区域罚、VOLL、折现率、\(S_{ij}\) 冻结)均有 1–2 组敏感性,结论与局限见 `docs/problem-B/limitations.md`;
