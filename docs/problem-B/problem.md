# B 题：考虑送端碳排不确定性的区域电网鲁棒碳流追踪与低碳调度

来源：`competition_question/B题/B题.pdf`（3 页）

## 1. 背景

某省一次能源存量不足，煤炭、天然气、外来电力供给缺口显著，对外省能源调入存在刚性需求。省内各区域产业结构、本地电源、消费规模与发展阶段分化明显。

已搭建多区域联动调度体系：区域间有电力互送通道，既可从省外或省内其他区域购电，也可外送富余电力。不同来源电力的碳排放强度差异显著，区域用电碳排放责任无法仅靠本地出力核算。

未来五年将分批落地工业节能、建筑绿色化、交通电气化、分布式新能源、需求侧响应等工程。项目间存在协同增益、资源竞争、实施互斥等耦合，并叠加省外送端电力碳排放的随机波动。

附件给出 8 个区域 \(A1,\ldots,A8\) 的面板数据。数据来自不同监测系统，存在缺失、统计误差或口径不一致。

## 2. 符号与能量平衡

正常情况下，区域 \(i\) 在月份 \(t\) 应近似满足：

\[
G_{i,t} + I_{i,t}^{(\mathrm{out})} + \sum_{j \neq i} T_{j,i,t}
= D_{i,t} + \sum_{j \neq i} T_{i,j,t} + L_{i,t}
\tag{1}
\]

| 符号 | 含义 |
|------|------|
| \(G_{i,t}\) | 区域 \(i\) 本地发电量 |
| \(I_{i,t}^{(\mathrm{out})}\) | 省外输入电量 |
| \(T_{j,i,t}\) | 区域 \(j\) 向区域 \(i\) 的输电量 |
| \(D_{i,t}\) | 终端用电量 |
| \(L_{i,t}\) | 输配电损耗 |

因测量误差，（1）式不一定严格成立。电量单位除特别说明外为 **GWh**。换算：

\[
\text{电量}(\mathrm{GWh})\times\text{排放因子}(\mathrm{kgCO_2/kWh})
= \text{碳排放量}(\mathrm{ktCO_2})
\]

## 3. 问题清单

### 问题一：多源能源数据的一致性校正与可信性评价

- 附件 1：2025 年逐月本地发电、省外输入、区域间输入输出、终端用电。
- 附件 2：另一套年度汇总与辅助监测数据。两套数据可能不一致。
- 任务：
  1. 识别异常、缺失和口径不一致。
  2. 建立数据校正模型，尽量保留原始观测，使结果满足区域能源平衡。
  3. 估计区域间输电通道损耗水平。
  4. 分析哪些观测对最终校正结果影响较大。

### 问题二：区域电力碳流追踪与碳排放责任分担

- 输入：校正后能源数据 + 附件 3（发电结构、外来电来源结构、碳排放因子）。
- 任务：
  1. 建立区域电力碳流追踪模型，分析省外输入、区域间传输和终端消费中的碳排放流动。
  2. 计算各区域**逐月终端用电碳排放强度**，追溯来源。
  3. 分别按**发电地承担**、**用电地承担**核算区域碳排放责任。
  4. 设计兼顾生产责任与消费责任的分担方法，并说明合理性。

### 问题三：区域碳预算分配与低碳项目组合优化

- 附件 4：2026–2030 年区域经济发展、能源需求、碳排放控制。
- 附件 5：候选项目投资、建设周期、节能减排效果及建设约束。
- 约束：各区域基本能源需求 + 全省年度碳排放控制。
- 任务：确定 2026–2030 年各区域项目实施顺序和建设规模，使五年低碳转型综合成本尽可能合理；分析优先项目，以及投资规模或碳目标变化时方案是否显著变化。

### 问题四：送端碳排不确定性与突发事件下的鲁棒滚动调控

- 省外输入电力的电源结构随季节和供需变化，碳排放强度非固定。
- 附件 6：省外输入电力碳排放强度的波动区间或典型情景（**以 Excel 为准**；题面第 3 页对附件 6 的“突发事件”文字与表格不一致）。
- 任务：
  1. 分析问题三五年方案在送端碳排不确定下的稳定性。
  2. 建立优化模型，给出不利情景下仍满足供能和碳排放要求的调整方案。
  3. 比较确定性方案与调整方案的投资成本和减排效果，说明抗风险代价。

### 问题五：面向政府或企业的决策咨询报告

综合前四问，选择下列之一作为决策主体，撰写约 **1000 字**咨询报告，题目自拟：

- 省级能源主管部门
- 电力管理部门
- 电网企业
- 综合能源企业
