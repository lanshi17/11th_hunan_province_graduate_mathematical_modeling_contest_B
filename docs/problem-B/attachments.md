## 附件 6A：送端碳因子不确定区间（2028–2030）

只刻画省外输入碳因子相对问题三基准路径的偏离，**不改变**本地火电/水电/风电/光伏因子。

记问题三中区域 \(i\)、年份 \(t\) 的基准省外输入因子为 \(\bar e_{i,t}\)，问题四取

\[
e_{i,t} = \bar e_{i,t}\cdot \xi_{i,t}
\]

\(\xi_{i,t}\) 由本表给出。若采用预算不确定集，令不利方向归一化偏离

\[
z_{i,t}=\frac{\xi_{i,t}-1}{\xi^U_{i,t}-1},\quad
0\le z_{i,t}\le 1,\quad
\sum_i z_{i,t}\le \Gamma_t
\]

年度不确定预算：\(\Gamma_{2028}=2\)，\(\Gamma_{2029}=2.5\)，\(\Gamma_{2030}=3\)。

高碳送端较敏感：A1、A2、A4、A6；其余相对温和。\(\xi\) 区间随年份扩大，例如 A4：2028 为 \([0.980,1.025]\)，2030 为 \([0.965,1.040]\)。

## 附件 6B：典型情景

情景不赋予固定概率。S2、S3 按附件 6A 区间与 \(\Gamma_t\) 构造。若做概率分析须自行设定并说明依据。

| 编号 | 名称 | 用途 |
|------|------|------|
| S0 | 基准情景 | 全部 \(\xi=1\)，按问题三基准路径 |
| S1 | 低碳送端情景 | 各区域接近当年区间下界（有利） |
| S2 | 阶段性偏高情景 | 若干重点受电区域中等同步上行 |
| S3 | 关键送端高碳情景 | A2、A4 等接近不利上界（压力测试） |

每年 2028–2030 各给一行乘数。
