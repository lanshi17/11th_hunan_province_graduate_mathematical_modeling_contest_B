# 问题 1 结果填写说明

填写文件：`competition_question/A题/附件6-问题1结果.xlsx`

## 核心原则

- **每个包裹占一行**。模板已预置全部 1998 个包裹及其基本属性。
- 只填写**黄色区域**；不要删除、增加或合并数据行；不要修改工作表名称和列名。
- A 类每件 \(1\,\mathrm{kg}\)，B 类每件 \(5\,\mathrm{kg}\)。包裹编号、需求点编号、类型和重量已给定，不得改动。
- 时刻以主干运输开始 \(t=0\) 为起点，单位小时；建议至少保留 **4 位小数**。
- 同一主干车辆任务、同一无人机任务在多行中重复出现时，车辆、离开中心时刻、到货时刻、起飞时刻、返回时刻、总载重和总航程必须一致。
- 问题 1 仍受无人机单次运输 **40 km 航程**限制；仅忽略充电时间和费用，不忽略飞行时间、设备占用和主干运输时间。
- **完工时间** = 所有包裹送达时刻的最大值，不是最后一架无人机的返回时刻。
