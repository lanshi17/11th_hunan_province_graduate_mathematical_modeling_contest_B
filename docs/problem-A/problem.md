# A 题：无人车-无人机协同配送优化问题研究

来源：`competition_question/A题/A题.pdf`（4 页）

## 1. 背景与场景

湖南省兼具山地、丘陵、河网湖区和城镇密集区。无人车载重量大、运行稳定，适合物流中心与物流点之间的主干运输；无人机路径短、机动性强，适合道路较差或车辆不可达区域的末端配送。

试点对象：低重量、高价值、对安全性和时效性要求较高的包裹，作为人工配送的补充。

## 2. 空间与网络

| 项目 | 规定 |
|------|------|
| 区域 | \(100\,\mathrm{km}\times 100\,\mathrm{km}\) 二维平面 |
| 坐标 | 左下角 \((0,0)\)，右上角 \((100,100)\) |
| 初始物流中心 | \(C_0\)，1 个，仓储与干线集散 |
| 物流点 | 22 个（\(P01\)–\(P22\)），可作无人车停靠、中转、无人机起降基站 |
| 主干道路 | 39 条，无人车必须沿该路网行驶 |
| 需求点 | 包裹最终目的地（小区 / 居民楼无人机快递仓） |

节点坐标与区域类型见 [attachments.md](attachments.md) 附件 1；路网见附件 2。

区域类型：`urban`（城区）、`hill`（丘陵区）、`mountain`（山区）、`lake`（湖区）。

道路类型：`core_trunk`、`trunk`、`hill_trunk`、`mountain_trunk`、`lake_trunk`。未特别说明时按**双向通行**；道路容量充分，不考虑同时承载车辆数限制。

## 3. 运力与运行规则

### 3.1 主干物流无人车

| 参数 | 取值 |
|------|------|
| 初始配置 | \(C_0\) 配备 **6 台** |
| 最大载重 | \(300\,\mathrm{kg}\) |
| 行驶速度 | \(30\,\mathrm{km/h}\) |
| 用途 | 物流中心 \(\leftrightarrow\) 物流点干线运输 |
| 路径约束 | 必须沿附件 2 路网行驶 |

问题 4 中两个物流中心合计 **8 台**。

### 3.2 无人机

- 固定部署在物流点，**不与具体无人车绑定**。
- 从所属物流点起飞，完成配送后**返回原物流点**。
- 最大载重 \(6\,\mathrm{kg}\)；单次飞行可服务多个需求点，总重不得超过 \(6\,\mathrm{kg}\)。
- 飞行距离按**欧氏距离**计算。
- 问题 1：每个物流点固定 **2 架**；不考虑充电及配套设施，但**仍受 40 km 航程、飞行时间和设备占用约束**。
- 载重–速度关系（表 2）：

| 当前载重 \(w\) | 飞行速度 |
|----------------|----------|
| \(0 < w \le 2\,\mathrm{kg}\) | \(40\,\mathrm{km/h}\) |
| \(2 < w \le 4\,\mathrm{kg}\) | \(35\,\mathrm{km/h}\) |
| \(4 < w \le 6\,\mathrm{kg}\) | \(30\,\mathrm{km/h}\) |

### 3.3 轻型物流车（问题 2 起）

部署在物流点，承担地面可达需求点的末端配送和小批量调拨。

| 参数 | 取值 |
|------|------|
| 最大载重 | \(100\,\mathrm{kg}\) |
| 主干路网速度 | \(30\,\mathrm{km/h}\) |
| 非主干 / 末端道路速度 | \(20\,\mathrm{km/h}\) |
| 续航 | \(100\,\mathrm{km}\) |
| 充电时间 | \(60\,\mathrm{min}\) |
| 充电成本 | \(8\) 元/次 |

末端行驶距离：

\[
d = \lVert x_i - x_j \rVert_2 \times \kappa_j
\]

其中 \(\kappa_j\) 为需求点 \(j\) 的**末端道路绕行系数**。系数为空白则地面车辆不可达，不得由轻型物流车直接配送。

### 3.4 可达性

- `no`：地面车辆不可直达，**全部包裹必须无人机配送**。
- `yes`：可由无人机配送；问题 2、3、4 中也可由轻型物流车配送。

### 3.5 时间与货物假设

- 所有货物开始时位于物流中心；配送开始时刻 \(t = 0\)。
- **不考虑**包裹装卸和投递时间。
- C 类时限自 \(t=0\) 起算，等待、干线运输和末端配送时间均计入。

## 4. 包裹经济口径（表 1）

| 类型 | 单件重量 | 准时/完成收益 | 超时或未完成 | 说明 |
|------|----------|---------------|--------------|------|
| A 类普通包裹 | \(1\,\mathrm{kg}\) | \(4\) 元/件 | 不计收益 | 数量多，无特殊时限 |

## 5. 设备投资与日均净收益（表 3；问题 2–4）

| 设备 | 折算投资和维护成本 | 续航/航程 | 充电时间 | 充电成本 | 其他 |
|------|-------------------|-----------|----------|----------|------|
| 无人机及配套充电设施 | \(5\) 万元/架 | \(40\,\mathrm{km}\) | \(30\,\mathrm{min}\) | \(2\) 元/次 | 最大载重 \(6\,\mathrm{kg}\)，速度见表 2 |
| 轻型物流车及配套充电设施 | \(15\) 万元/台 | \(100\,\mathrm{km}\) | \(60\,\mathrm{min}\) | \(8\) 元/次 | 载重与速度见 §3.3 |

约束与折算：

- 问题 2、3：**每个物流点**无人机 + 轻型物流车设备投资总额 \(\le 50\) 万元。
- 一次性投资及维护成本按 **3 年、每年 365 天** 折为日均投资成本，并计入充电成本。

\[
\text{日均净收益}
= \text{包裹配送收入}
- \text{C 类超时赔付}
- \text{设备日均投资成本}
- \text{充电成本}
\]

## 6. 问题清单

请根据附件 1–5 与表 1–3 建立模型并设计算法。

### 问题 1（300 个需求点，时效最短）

- 数据：附件 3（300 个 A/B 类需求点）。
- 配置：每物流点 **2 架无人机**；**不引入**轻型物流车；不考虑充电及配套设施。
- 决策：物流点服务范围；主干无人车路径与批次；无人机配送批次与飞行路径。
- 目标：所有包裹送达的**配送完成时间最短**；同时给出干线网络运输总里程。
- 提交：按附件 7 将逐包裹结果填入 `附件6-问题1结果.xlsx`，与论文一并提交。

完工时间定义（附件 7）：取**所有包裹送达时刻的最大值**，不是最后一架无人机的返回时刻。

### 问题 2（800 个需求点，时效 + 收益）

- 数据：附件 4 = 附件 3 的 300 点 + 新增 500 点。
- 引入末端轻型无人车；确定各物流点无人机与轻型物流车配备数量。
- 须完成全部 A、B 类包裹配送。
- 综合配送时效和日均净收益，给出协同配送方案。
- 须报告：运输成本、总配送时间、干线网络运输总里程、包裹平均送达时间。

### 问题 3（1000 个需求点，含 C 类时限）

- 数据：附件 5 = 附件 4 的 800 点 + 新增 200 个 C 类时限需求点。
- 在问题 2 框架上重新求解。
- 新增指标：**C 类包裹准时率**。

### 问题 4（新增物流中心选址）

- 依托某个**既有物流点**新增一个物流中心；新增中心经该物流点接入现有主干路网。
- 选址范围为 22 个物流点之一，并视为与该点**共址**。
- 两中心合计 8 台主干物流无人车。
- 由新增中心服务的需求点，货物可视为初始存放于该中心。
- 无人机和轻型物流车配置数量**同问题 3 方案**。
- 新增中心建设成本和主干运输成本**不计入**经济性评价。
- 综合配送时效和日均净收益，确定最佳位置并给出方案。
- 须报告：两中心及各物流点的无人车/无人机配置数量、运输成本、总配送时间、干线网络运输总里程、包裹平均送达时间、C 类准时率。
